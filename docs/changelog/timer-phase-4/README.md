# Timer phase 4 · Foreground speech and screen wake

- Countdown and Interval Timers can speak completion and keep the screen awake while running. Enable either option under **Advanced**.
- Interval Timers can speak the three-second preparation cue and count down the final seconds. Short repetitions start speaking after the first second and use a tone at the end.
- Speech plays on the visible dashboard and respects each timer’s mute setting. Completion announcements take priority over countdown numbers.
