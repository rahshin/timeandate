# Dashboard design phase 3 · Find unfinished timers

The Dashboard now shows a shortcut when a Countdown or Interval Timer is running or paused on another dashboard. With one unfinished timer, the shortcut opens its card directly. With several, a compact list shows each timer's dashboard and whether it is running, paused, or restored paused.

The original timer keeps its deadline when you switch boards. Use the same controls on its card. The shortcut disappears when other boards have no unfinished runs.
